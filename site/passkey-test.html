Passkey test

Does your password manager's passkey support PRF? A Trikey guardian needs it for a passkey that unlocks key 3 after a restart (the design: passkey-unlock.md). Without it, a passkey could only sign you in.

  1. Make a test passkey. Your browser or password manager (Proton Pass, 1Password, iCloud, Google…) asks where to save it. Pick the one you want to test. It is named “Trikey passkey test” and is only for this page.

  2. Use it. Sign in with the passkey you just made. This is where PRF either answers or not.

Nothing is sent anywhere: the page has no server, and the passkey's secret output is never shown, only whether it came back and how long it is. Afterwards you can delete “Trikey passkey test” from your password manager. Run it once per device and password manager you might use.

### 3. Umbrel App Store, official (github.com/getumbrel/umbrel-apps)

Trikey is on Umbrel today through its own community app store. The official store takes PRs to `getumbrel/umbrel-apps`,
following its `AGENTS.md` and repo skills. Its "App Store Standard" asks that every app open in the browser to a web UI or
setup flow with a clear next step, without SSH or manual file edits. The guardian's web UI should meet that. A listing on
apps.umbrel.com would be a strong, earned link. It's a packaging task rather than a text submission, so the text below is
only the store description:

```
Trikey Guardian is key 3 of a Trikey 2-of-3 bitcoin wallet. It co-signs your phone's everyday payments up to a daily limit you set, needs your hardware wallet for anything larger or for loosening its rules, and runs a 7-day Delay & Notify recovery with alerts if your phone is lost. It reads the chain from your Umbrel's own node and talks to your phone over encrypted nostr relays, with no open ports. Pre-alpha and not audited: use it on test networks.
```

### 4. Start9 Community Registry

Current process (docs.start9.com, packaging, "Publishing", StartOS 0.4.0.x): email submissions@start9.com with a link to
the public GitHub repository of the package. Start9 merges a PR against its fork; a workflow builds the package to
community-beta, and it is promoted to the Community Registry once you agree. The older 0.3.5 docs also require it to pass
backup and restore testing and to run on a low-resource device. Draft email:

```
Subject: Community Registry submission: Trikey Guardian

Hello,

I'd like to submit Trikey Guardian to the Community Registry. It is the co-signing key of Trikey, an open-source 2-of-3 bitcoin multisig wallet in which the user holds all three keys: it co-signs phone payments up to a daily limit and runs a time-delayed recovery with alerts, using the box's own Bitcoin node and Electrs.

Package source: https://github.com/TheIcarusWings/trikey/tree/main/packaging/start9
Project: https://github.com/TheIcarusWings/trikey

It is pre-alpha and not audited, and we tell users to try it on test networks. Happy to start in community-beta and fix whatever your review finds.

Thank you,
TheIcarusWings
```

are handled in its GitLab project (gitlab.com/walletscrutiny/walletScrutinyCom); its "How to Contribute" page describes
the ways to take part. The review would be earned, and it fits Trikey's open builds and the reproducible Android CI work
(#231). Draft issue:

```
Title: Wallet request: Trikey (Android, 2-of-3 multisig)

Trikey is an open-source 2-of-3 bitcoin multisig wallet (phone key + any hardware wallet + a self-hosted co-signer). The Android app is distributed as signed APKs from GitHub releases and through Zapstore/Obtainium; release assets are signed with the project's nostr key (packaging/VERIFY.md).

Source: https://github.com/TheIcarusWings/trikey
Website: https://trikey.app

It is pre-alpha and not audited. We are working on reproducible Android builds (CI measuring APK reproducibility) and would welcome a review of the build once that lands.
```
